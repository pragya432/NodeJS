## Objective

This lab demonstrates asynchronous programming in Node.js using callbacks, Promises, async/await, Promise chaining, and Promise.all().

## Files and Their Purpose

| File | Description |
|---|---|
| `callback-version.js` | Demonstrates nested callbacks for placing, tracking, and confirming a food order. |
| `promise-version.js` | Demonstrates Promise fulfillment and rejection using `.then()` and `.catch()`. |
| `chaining-version.js` | Demonstrates sequential asynchronous operations using Promise chaining. |
| `async-await-version.js` | Demonstrates the same order lifecycle using async/await and try/catch. |
| `concurrent-orders.js` | Demonstrates running multiple orders concurrently using Promise.all(). |
