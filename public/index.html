ABOUT THE LABORATORY

Learning Node.js
through implementation.

This portfolio documents my practical work for CS403NOD – Node.js. Each laboratory assignment focuses on understanding Node.js concepts through hands-on implementation, testing and API development.

The work progresses from understanding the Node.js runtime and executing basic programs to creating HTTP servers and building dynamic APIs using routes, parameters and JavaScript array methods.

From basic Node.js execution to dynamic API development.
