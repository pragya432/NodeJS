About This Portfolio

CS403NOD Node.js Laboratory Course

This academic portfolio documents the practical coursework completed for the CS403NOD — Node.js laboratory module in BCA VII Semester. The repository demonstrates foundational to advanced backend development concepts without reliance on external web frameworks.

Through seven structured laboratory experiments, key Node.js capabilities are explored — ranging from runtime CLI execution and built-in HTTP server creation to RESTful routing, URL query parsing, asynchronous execution with Promises and async/await, non-blocking file system I/O, and custom event-driven applications using EventEmitter.

Technologies & Core Concepts

Node.js

V8 JavaScript runtime environment for executing asynchronous, event-driven backend code.

⚡

JavaScript (ES6+)

Modern ES6+ syntax including arrow functions, destructuring, classes, Promises, and async/await.

🌐

HTTP Module

Built-in Node.js HTTP server module (`http.createServer`) handling request and response streams.

🔗

REST API

RESTful architectural endpoints, dynamic path routing parameters, JSON responses, and HTTP status codes.

📦

npm

Node Package Manager for project initialization (`package.json`) and script lifecycle management.

📁

File System (fs)

Asynchronous file operations using callbacks, Promises (`fs.promises`), and stream-based I/O.

📡

EventEmitter

Node.js `events` module for subscribing listeners (`.on`, `.once`), emitting custom events, and handling error traps.
