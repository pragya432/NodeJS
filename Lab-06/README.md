# CS403NOD – Node.js

## Lab Assignment – 06

**Lab Number:** 06

**Topic:** Working With The File System (fs) Module

## Objective

This lab demonstrates how to work with the Node.js File System (`fs`) module. It covers synchronous and asynchronous file reading, writing, appending, deleting files, using Promises with async/await, and creating a simple command-line notes application.

## Files and Their Purpose

| File | Description |
|---|---|
| `sample.txt` | Contains sample text used for file-reading operations. |
| `read-async.js` | Demonstrates asynchronous file reading using `fs.readFile()`. |
| `read-sync.js` | Demonstrates synchronous file reading using `fs.readFileSync()`. |
| `write-file.js` | Demonstrates creating and overwriting a file using `fs.writeFile()`. |
| `append-file.js` | Demonstrates adding content to an existing file using `fs.appendFile()`. |
| `delete-file.js` | Demonstrates deleting a file using `fs.unlink()`. |
| `async-await-version.js` | Demonstrates file operations using `fs.promises` and async/await. |
| `add-note.js` | Adds timestamped notes to a file using command-line arguments. |
| `read-notes.js` | Reads and displays saved notes from `notes.txt`. |
| `reflection-notes.txt` | Contains answers to the reflection questions. |
| `README.md` | Contains information about the lab and its files. |
