# Lab 07 — Implementing EventEmitter — Event-Driven Programming

## Course

CS403NOD – Node.js

## Lab Number

07

## Topic

Implementing EventEmitter — Event-Driven Programming

## Objective

The objective of this laboratory is to understand Node.js EventEmitter and event-driven programming by creating custom events, registering multiple listeners, using `.once()`, handling errors, extending EventEmitter with a class, and building a real-time order tracking system.

## Files

- `events-basic.js` — Basic custom EventEmitter event
- `order-system.js` — Multiple listeners for an order event
- `once-vs-on.js` — Difference between `.once()` and `.on()`
- `error-handling.js` — Safe handling of error events
- `notification-center.js` — Custom class extending EventEmitter
- `order-tracker.js` — Real-time order tracking mini project
- `reflection-notes.txt` — Reflection notes

## How to Run

Run each JavaScript file using Node.js.

```bash
node events-basic.js
node order-system.js
node once-vs-on.js
node error-handling.js
node notification-center.js
node order-tracker.js
